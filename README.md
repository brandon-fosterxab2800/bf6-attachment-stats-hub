## What This Project Contains

BF6 Attachment Database provides a web-accessible reference for Battlefield 6 weapon attachments. Reverse-engineered material is grouped across all nine attachment slots, allowing users to inspect attachment effects, tradeoffs, stat connections, and available customization choices from a single interface.

Alongside effect labels and tier-based stat ladders, the project includes attachment archetypes and a formula for estimating how attachment costs are calculated. The reference currently covers 163 barrel names, 15 ammunition slot types, and an error log for discrepancies identified in publicly available sources.
